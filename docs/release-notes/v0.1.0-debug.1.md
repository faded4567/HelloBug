# HelloBug v0.1.0-debug.1

这是首个公开的 debug 测试版，仅用于受控环境下的侧载测试和功能验证，不是生产版本。

## 包含内容

- Android release-mode APK：支持完成 App 引导、连接中继、配对 daemon、查看和发起编码 Agent 会话。
- daemon 发布包：包含已编译的 daemon 与协议包；首次启动会在目标 macOS/Linux 机器安装与平台匹配的生产依赖。
- server + daemon 本地联调和自托管文档。

## 安装 APK

1. 下载 `hellobug-0.1.0-debug.1-android-release-debug-signed.apk` 与同名 `.sha256` 文件。
2. 在下载目录执行 `shasum -c hellobug-0.1.0-debug.1-android-release-debug-signed.apk.sha256`，确认输出为 `OK`。
3. 将 APK 传到 Android 设备后安装，或执行：

   ```bash
   adb install -r hellobug-0.1.0-debug.1-android-release-debug-signed.apk
   ```

4. 按仓库 README 启动 relay 和 daemon，随后在 App 中输入 relay 地址、扫描 QR payload 或输入 daemon 输出的六位配对码，并核对 SAS。

## 启动 daemon

```bash
tar xzf hellobug-daemon-0.1.0-debug.1.tar.gz
cd hellobug-daemon-0.1.0-debug.1

HELLOBUG_DAEMON_SERVER_URL=wss://relay.example.com/v1/relay \
HELLOBUG_DAEMON_BOOTSTRAP_TOKEN=<bootstrap-token> \
HELLOBUG_DAEMON_ALLOWED_PATHS="/你的工作区绝对路径" \
./start.sh
```

daemon 需要 Node.js 20+、npm，以及本机已安装的 Claude Code 或 Codex。首次注册后会保存本地凭据，后续启动不再需要 bootstrap token。

## 已知限制

- APK 使用 Android Debug 证书签名，只能用于测试侧载，不能用于应用商店发布；后续正式签名版本不能直接覆盖安装此 debug 包。
- 当前 Android 包没有 Firebase `google-services.json`，FCM 推送不可用。
- iOS 发布包尚未提供。
- V1 仍在开发，远程访问时必须使用 TLS 和 `wss://`，不要将 daemon 的允许目录设为整个家目录。
